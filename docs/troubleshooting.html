🔴 مشکلات تلگرام و اتصال

معمولیخطای FloodWait (محدودیت تلگرام)

تلگرام محدودیت را رعایت می‌کند و از ارسال پیام بیش از حد جلوگیری می‌کند.

علت: ارسال زیاد پیام در مدت کوتاه، حالت اتوماتیک آنلاین بودن، یا ارسال انبوه بدون تأخیر.

راه‌حل:

  • از دکمه EMERGENCY STOP در بخش مرکز امنیت استفاده کنید
  • فاصله زمانی ارسال (delay) را به 5-10 ثانیه افزایش دهید
  • سطح آرام‌سازی حساب (Account Warming) را به beginner برگردانید
  • منتظر اتمام زمان محدودیت (معمولاً ۱ تا ۲۴ ساعت) بمانید
  • سقف روزانه پاسخ‌گویی (max_responses_per_day) را کاهش دهید

خطاخطای ۴۰۱ - احراز هویت ناموفق

توکن ورود معتبر نیست.

راه‌حل:

  • با نام کاربری و رمز درست وارد شوید
  • توکن را تازه‌سازی کنید: POST /api/auth/refresh
  • توکن منقضی شده است؛ دوباره وارد شوید
  • اگر مشکل ادامه داشت، رمز عبور را تغییر دهید

خطاخطای اتصال تلگرام

امکان اتصال به تلگرام وجود ندارد.

علل:

  • TELEGRAM_API_ID یا TELEGRAM_API_HASH اشتباه است
  • شماره موبایل وارد نشده
  • سرور تلگرام در دسترس نیست
  • پروکسی لازم است

راه‌حل:

  • api_id و api_hash را از my.telegram.org بررسی کنید
  • TELEGRAM_PHONE را در فایل .env وارد کنید
  • اتصال را دوباره امتحان کنید: POST /api/account/session/connect
  • لاگ‌ها را بررسی کنید: storage/logs/app.log

هشدارحساب بن شد (Banned/Restricted)

تلگرام حساب شما را محدود کرده است.

علت: اسپم، استفاده غیرمجاز از API، فعالیت سنگین.

راه‌حل:

  • فوراً EMERGENCY STOP را فعال کنید
  • بخش مرکز امنیت را بررسی کنید
  • ۲۴ تا ۴۸ ساعت صبر کنید
  • اگر ادامه داد، پشتیبانی تلگرام را بزنید

🟡 مشکلات دیتابیس

خطاخطای دیتابیس (sqlite/permission)

دسترسی به فایل دیتابیس وجود ندارد.

راه‌حل:

  • پوشه storage/ وجود داشته باشد: mkdir -p storage
  • مجوز فایل‌ها را بررسی کنید: chmod -R 755 storage/
  • مایگریتن اجرا کنید: python -m backend.app.main migrate
  • اگر فایل SQLite خراب است، پشتیبان بگیرید و فایل را حذف و مایگریتن مجدد کنید

هشدارجدول‌ها ایجاد نشده‌اند

مایگریتن اجرا نشده.

راه‌حل:

python -m backend.app.main migrate

اگر باز هم خطا داد، کل دیتابیس را ریست کنید:

rm storage/database.db
python -m backend.app.main migrate

معمولیعدم تطابق نسخه دیتابیس

مدل‌ها تغییر کرده‌اند اما مایگریتن اجرا نشده.

راه‌حل:

python -m backend.app.main makemigration -m "update models"
python -m backend.app.main migrate

🔵 مشکلات ردیس و صف کار

خطاخطای اتصال Redis

ردیس در دسترس نیست.

راه‌حل:

  • بررسی کنید ردیس اجرا شده: redis-cli ping (باید PONG برگرداند)
  • آدرس ردیس در فایل .env درست باشد
  • با داکر: docker-compose ps بررسی کنید
  • اگر ردیس روشن نیست: docker-compose up -d redis

هشدارورکر Celery اجرا نمی‌شود

کارهای زمان‌بندی و پخش انبوه انجام نمی‌شوند.

راه‌حل:

  • ردیس را بررسی کنید (بخش بالا)
  • ورکر را اجرا کنید: celery -A worker.tasks.celery_app worker -l info
  • با داکر: docker-compose up -d worker

🟢 مشکلات فرانت‌اند

خطاداشبورد سفید / خالی / خطای ۴۰۴

فرانت‌اند ساخته نشده است.

راه‌حل:

cd frontend
npm install
npm run build

سپس سرور را ریستارت کنید.

هشدارخطای CORS (دسترسی ممنوع)

فرانت‌اند نمی‌تواند به API متصل شود.

راه‌حل:

  • پورت فرانت‌اند (3000 یا 5173) در ALLOWED_ORIGINS .env اضافه شود
  • مثال: ALLOWED_ORIGINS=http://localhost:5173,http://localhost:3000

معمولیزبان RTL فارسی نشان نمی‌دهد

زبان در تنظیمات تغییر نکرده.

راه‌حل:

  • به بخش تنظیمات بروید و زبان را روی fa (فارسی) تغییر دهید
  • مرورگر را رفرش کنید

🔧 مشکلات عمومی

خطاخطای ModuleNotFoundError

ماژول‌های پایتون پیدا نشدند.

راه‌حل:

pip install -e ".[dev,ai,media]"
pip install -r requirements.txt

مطمئن شوید در ریشه پروژه هستید.

هشدارخطای settings.LOGS_DIR یا settings.FRONTEND_DIR

بایگ‌های قبلی از اختصاص ویژگی به Pydantic ساختار مربوطه.

راه‌حل: نسخه فعلی (v1.0.0) این مشکل را رفع کرده است. اگر باز هم دیدید، کد را به‌روزرسانی کنید:

git pull origin main
pip install -e ".[dev]"

اطلاعاتخطای FFmpeg یا Whisper

ابزارهای تبدیل رسانه نصب نیستند.

راه‌حل:

  • FFmpeg نصب باشد: sudo apt install ffmpeg
  • لینوکس: sudo apt install ffmpeg
  • ویندوز: دانلود از ffmpeg.org

📊 بررسی لاگ‌ها

در بیشتر موارد، جواب مشکل در لاگ‌ها موجود است:

cat storage/logs/app.log | tail -100

یا از داشبورد، به بخش لاگ‌ها بروید.

❓ سؤال‌های متداول (FAQ)

سؤالجواب
می‌توانم بدون Redis استفاده کنم؟بله، بخش‌های اصلی (آرشیو، پیام‌ها) بدون ردیس کار می‌کنند. اما زمان‌بندی و پخش انبوه نیاز به ردیس دارند.
چرا خطای FloodWait دارم؟تلگرام محدودیت ارسال دارد. از Emergency Stop استفاده کنید و صبر کنید.
داشبورد رنگی نمی‌شود؟فرانت‌اند ساخته نشده. cd frontend && npm install && npm run build اجرا کنید.
کدام دیتابیس پیشنهاد می‌شود؟SQLite برای تست و توسعه، PostgreSQL برای تولید.
چگونه رمز عبور ادمین را تغییر دهم؟از بخش تنظیمات → تغییر رمز عبور یا دستور: python -m backend.app.main init-admin
آیا استفاده از سلف‌بات تخلف تلگرام است؟تلگرام استفاده از userbot را محدود می‌کند. این پلتفرم شامل قابلیت‌های حفاظتی مانند آرام‌سازی حساب و Emergency Stop است.
✅ اگر مشکل همچنان وجود داشت: لاگ‌ها را بررسی کنید (storage/logs/app.log) یا بخش لоги داشبورد را ببینید. اکثر مشکلات در آنجا توضیح داده شده‌اند.
