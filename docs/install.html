🛠 پیش‌نیازها

قبل از شروع نصب، مطمئن شوید تمام ابزارهای زیر نصب هستند:

الزامیپایتون ۳.۱۱ یا بالاتر

بررسی کنید: python --version یا python3 --version

الزامیFFmpeg

برای تبدیل رسانه‌ها (ویدیو→صد، متن→صد و ...) لازم است.

لینوکس: sudo apt install ffmpeg
ویندوز: دانلود از ffmpeg.org

الزامیRedis

برای صف کارها (زمان‌بندی، پخش انبوه، تکرار پیام).

لینوکس: sudo apt install redis-server
داکر: در docker-compose.yml خودکار است.

الزامیمشخصات API تلگرام

از سایت my.telegram.org اطلاعات api_id و api_hash را بگیرید.

📋 روش‌های نصب

روش ۱: نصب خودکار لینوکس (توصیه‌شده)

۱. دسترسی به پروژه

پروژه را کلون کنید و وارد پوشه شوید.

۲. اجرای اسکریپت نصب

دستورات زیر را با دسترسی ریشه اجرا کنید:

chmod +x install.sh
./install.sh

اسکریپت به‌طور خودکار پایتون، وابستگی‌ها و پوشه‌ها را تنظیم می‌کند.

روش ۲: نصب دستی (هر سیستمی)

۱. نصب پایتون

اطمینان از وجود پایتون ۳.۱۱+:

python --version

۲. نصب وابستگی‌ها

pip install --upgrade pip
pip install -e ".[dev,ai,media]"

پکیج‌های نصب‌شده شامل: FastAPI, Telethon, SQLAlchemy, Pydantic, Celery, Redis, OpenAI, FFmpeg و ...

۳. تنظیم فایل محیطی

cp .env.example .env

سپس فایل .env را ویرایش کنید.

روش ۳: نصب ویندوز

۱. اجرای نصب‌کننده ویندوز

.\install.ps1

در PowerShell با دسترسی مدیر اجرا کنید.

۲. روش جایگزین (فایل دستی)

install.bat

۳. نصب دستی ویندوز

پایتون را از python.org نصب کنید (حتماً گزینه "Add to PATH" را فعال کنید).

pip install -e ".[dev,ai,media]"
copy .env.example .env

روش ۴: نصب با داکر (پروDUCTION)

۱. تنظیم فایل .env

مشخصات API تلگرام و کلیدهای امنیتی را وارد کنید.

۲. اجرای داکر کامپوز

docker-compose up -d

با داکر کامپوز تمام سرویس‌ها (اپلیکیشن، ورکر، بیت، ردیس) به‌صورت هم‌زمان اجرا می‌شوند.

۳. ایجاد کاربر ادمین

docker-compose exec app python -m backend.app.main init-admin

⚙️ تنظیم فایل .env

فایل .env تنظیمات اصلی پروژه است. پس از کپی، حتماً مقادیر زیر را تغییر دهید:

متغیرمقدار پیش‌فرضتوضیح
TELEGRAM_API_ID—شناسه اپلیکیشن از my.telegram.org
TELEGRAM_API_HASH—هش اپلیکیشن
TELEGRAM_PHONE—شماره موبایل (اختیاری)
DATABASE_URLsqlite:///./storage/database.dbآدرس دیتابیس (SQLite/PostgreSQL/MySQL)
REDIS_URLredis://localhost:6379/0آدرس Redis
APP_SECRET_KEYchange-this-keyکلید محرمانه اپلیکیشن
JWT_SECRET_KEYchange-this-keyکلید امضا توکن
ENCRYPTION_KEYchange-this-keyکلید رمزنگاری داده‌ها
CSRF_SECRET_KEYchange-this-csrf-keyکلید محافظت CSRF
AI_PROVIDERopenaiproviders: openai, gemini, deepseek, local
OPENAI_API_KEY—کلید OpenAI برای هوش مصنوعی
APP_PORT8000پورت وب‌سرور
SCHEDULER_TIMEZONEUTCمنطقه زمانی
RATE_LIMIT_REQUESTS30تعداد درخواست مجاز در هر پنجره زمانی
⚠️ هشدار امنیتی: قبل از اجرا در محیط تولید، تمام مقادیر change-this-key را با مقادیر تصادفی و قوی جایگزین کنید. هیچ‌وقت کلیدهای محرمانه را در فایل Git قرار ندهید.

🔌 تنظیم دیتابیس

پیش‌فرض SQLite است اما برای محیط تولید پیشنهاد می‌شود:

PostgreSQL

DATABASE_URL=postgresql://user:password@localhost:5432/telegram_bot

با پایتون نصب:

pip install asyncpg

MySQL/MariaDB

DATABASE_URL=mysql+pymysql://user:password@localhost:3306/telegram_bot

با پایتون نصب:

pip install pymysql

🚀 اجرای اولین بار

۱. اجرای میگریشن دیتابیس

python -m backend.app.main migrate

جدول‌های دیتابیس ایجاد می‌شوند.

۲. ایجاد کاربر ادمین

python -m backend.app.main init-admin

نام کاربری: admin  |  رمز: admin123

۳. اجرای سرور

python -m backend.app.main serve --reload

۴. باز کردن داشبورد

در مرورگر آدرس http://localhost:8000 را باز کنید.

با نام کاربری admin و رمز admin123 وارد شوید.

۵. اتصال تلگرام

به بخش تنظیمات بروید، api_id و api_hash را وارد کنید و اتصال را آزمایش کنید.

📦 ساخت داکر ایمیج

docker build -t telegram-self-bot:1.0 .
docker run -d -p 8000:8000 --env-file .env --name telegram-bot telegram-self-bot:1.0

🔄 بروزرسانی

# لینوکس/مک
git pull origin main
pip install -e ".[dev,ai,media]"
python -m backend.app.main migrate

# داکر
docker-compose pull
docker-compose up -d --build

❌ حذف

# ایستادن سرویس‌ها
python -m backend.app.main stop 2>/dev/null || true

# حذف فایل‌ها
rm -rf storage/logs/* storage/database.db

# داکر
docker-compose down -v
