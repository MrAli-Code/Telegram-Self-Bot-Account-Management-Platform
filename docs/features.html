📌 خلاصه

تلگرام سلف-بات پلتفرمی حرفه‌ای، ماژولار و Production-Ready برای مدیریت کامل اکانت تلگرام شماست. شامل ۲۰+ ماژول، ۵۰+ endpoint API، پشتیبانی از فارسی و انگلیسی، و قابلیت‌های روزآمد هوش مصنوعی.

🏗 معماری سیستم

🧩

بک‌اند (FastAPI)

پایتون ۳.۱۱+، REST API، WebSocket، SQLAlchemy ۲.۰، Pydantic v2

📱

فرانت‌اند (Vue 3)

Vue 3 + TypeScript + Pinia + Vue Router، پشتیبانی کامل RTL

🤖

تلگرام انجین (Telethon)

MTProto، مدیریت سشن، پردازش آپدیت، مدیریت FloodWait

⚙️

صف کار (Celery + Redis)

Celery worker + beat، Redis cache و broker

🗄

دیتابیس

SQLite (توسعه) / PostgreSQL / MySQL، Alembic migration

🐳

داکر

Docker + Docker Compose، ساخت ایمیج، deployment

🧠 ویژگی‌های جدید و روزآمد (Trending Features)

🔥 TRENDINGاتوماسیون چت هوش مصنوعی

معادل قابلیت Chat Automation تلگرام: اتصال AI به پروفایل شما برای پاسخ‌گویی خودکار. شخصیت‌ها (دوستانه، حرفه‌ای، فروشگاهی، پشتیبانی)، حداکثر پاسخ در روز، ساعت کاری، و پشتیبانی از چندین پرووایدر AI.

API: POST /automation/chat-automation/setup

🔥 TRENDINGآرام‌سازی حساب (Account Warming)

برای جلوگیری از محدود شدن حساب، این سیستم رفتارهای انسانی شبیه (تایپ، خواندن، مشاهده استوری، مرور فید) را به‌تدریج و در ۴ سطح (مبتدی تا کارشناس) اجرا می‌کند.

API: POST /automation/warming/start

🔥 TRENDINGمکالمات عصبی (Neuro Dialogs)

مکالمه با AI با زمینه و تاریخچه مکالمات. شخصیت‌های مختلف شامل دوزبانه فارسی/عربی. پاسخ‌ها طبیعی و شبیه انسان هستند.

API: POST /automation/neuro-dialog/create

🔥 TRENDINGفوروارد هوشمند

فوروارد پیام با فیلتر کلمات کلیدی، لیست سفید ارسال‌کننده، پیشوند/پسوند، و حذف علامت فوروارد.

API: POST /automation/smart-forward/create

🔥 TRENDINGمدیریت چند حساب

مدیریت چندین اکانت تلگرام از یک داشبورد. هر حساب با مشخصات API خودش و تنظیمات جداگانه.

API: POST /automation/multi-account/add

🔥 TRENDINGپارسر کاربران

استخراج لیست اعضا و مخاطبین از گروه‌ها و کانال‌ها برای پخش انبوه و هدف‌گیری.

🤖 AIچندین پرووایدر AI

پشتیبانی از OpenAI، Google Gemini، DeepSeek، OpenRouter، و مدل‌های محلی (Ollama). یک رابط کاری مشترک برای تعویض آسان پرووایدر.

🤖 AIشناسایی گفتار

تبدیل صدا به متن با Whisper و متن به صدا با FFmpeg.

🌐 API Reference

تمام endpointها در مسیر /api میزبانی می‌شوند. مستندات تعاملی در /api/docs (Swagger) و /api/redoc (ReDoc) در دسترس هستند.

Authentication

POST /api/auth/register — ثبت‌نام
POST /api/auth/login — ورود
POST /api/auth/refresh — تازه‌سازی توکن
GET /api/auth/me — اطلاعات کاربر
POST /api/auth/change-password — تغییر رمز
Authorization: Bearer <access_token>
